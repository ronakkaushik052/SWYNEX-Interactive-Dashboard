# SWYNEX – Interactive Sales Analytics Dashboard

## Project Overview
This project is developed as part of the SWYNEX Internship – Task 3. It focuses on building an interactive sales analytics dashboard using Python and data visualization libraries.

The dashboard helps analyze supermarket sales data through different visualizations and key performance indicators (KPIs).

## Objectives
- Analyze overall sales performance.
- Visualize product category-wise sales.
- Compare sales across different branches.
- Understand customer payment preferences.
- Analyze monthly sales trends.
- Provide interactive data exploration.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Average Sales
- Category-wise Sales Analysis
- Branch-wise Sales Analysis
- Payment Method Analysis
- Monthly Sales Trend
- Interactive Filters

## Project Files
- `SWYNEX_Task3_Interactive_Dashboard.ipynb` – Jupyter Notebook containing the project code.
- `SWYNEX_Task3_Interactive_Dashboard.html` – Interactive dashboard exported as an HTML file.

## How to Run
1. Download the project files.
2. Open the Jupyter Notebook.
3. Make sure the required Python libraries are installed.
4. Keep the dataset `cleaned_sales_data.csv` in the same folder.
5. Run the notebook cells sequentially.
